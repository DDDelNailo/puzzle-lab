# Puzzle Lab

Puzzle Lab is a desktop puzzle workbench built with Tauri + Svelte.

## What should it do?

* Play puzzles.
* Generate new puzzles.
* Validate moves.
* Detect completion.
* Solve puzzles.
* Visualize solving.
* Expandable to other puzzle types.

## What can it do?

### V1 - Play one Sudoku

* Hard-coded puzzle.
* Board rendering.
* Cell selection.
* Value entry.
* Given cells.
* Basic validation.
* Completion detection.
* Reset.
